# Release status

**No.** As of 2026-08-27, Bend2 has not been publicly released. The current
estimate is approximately 2026-09-02.

## The dated trail

- **2026-03-05**: launch-blocker list — HVM4 AOT compiler, HVM4 GPU
  runtime, Bend2–SupGen integration.
- **2026-07-18**: "Bend2 complete"; CUDA backend ported overnight from the
  Metal reference.
- **2026-08-12**: delay post (≈08-28 implied).
- **2026-08-27**: launch plan — copiable-kind fix, weekend testing, Monday
  presentation recording, possible Wednesday launch (≈09-02).

## What "released" will mean here

A public compiler (or repository with code), a license, and runnable
examples. Until all three exist, every Bend2 sample on this site stays
labeled documentation-only. This site is unofficial and not affiliated
with Higher Order Company.
